# Implementation log

One entry per implemented change, newest first. File: `YYYY-MM-DD-<short-slug>.md`.

| Date | Change | Ticket | Entry |
|---|---|---|---|

## Entry format

```markdown
# <title>

- Date: YYYY-MM-DD
- Ticket / requirement: <id>
- Author: <person or agent>

## What changed
<behaviour added or changed, in two to five lines>

## Where
<modules and files touched; new config keys, constants, adapters>

## Decisions
<patterns used and why; alternatives rejected; link an ADR if one was written>

## How it was verified
<tests added; commands run and results>

## Follow-ups
<known gaps, debt, next steps>
```
